# Education

Simplest blend pattern:

1. Match **required template multiset** (counts matter; order does not)
2. Require **caller owns** every asset
3. **Consume** inputs (burn or treasury)
4. **Mint** output template (production only — this lab returns an intent)

Hybrid FT+NFT recipes add a token leg; see `px-blend-hybrid-ft-plus-nft`.
